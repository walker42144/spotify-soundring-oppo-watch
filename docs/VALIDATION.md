# 验证与兼容性记录

## 官方资料确认

- OPPO 穿戴平台提供 Android 应用开发方向入口：https://open.oppomobile.com/new/introduction?page_name=wearabledevice 。公开网页不是 X3 专用接口的完整保证，不依赖未确认的专用表冠/后台能力。
- OAuth 使用 Spotify 官方 Authorization Code + PKCE，回环 URI 用显式 127.0.0.1。
- 播放控制、设备、歌单遵循 Web API；开发模式能力有政策限制，见 README 官方链接。

## 主机验证

- Kotlin/Android release 构建、R8、lint 通过。
- 15 项控制策略/平滑进度单元测试通过。
- 3 项 Python 加密配对测试通过。
- 读取与命令响应分离，不将任意成功字符串解析为 JSON 对象；控制失败不一概归因为会员。

## 国行真机

通用硬件：OWW261，Android 11 / API 30，466×466、密度 320、32 位 ARM。

- USB 侧载安装、官方授权、本地加密配对闭环完成。
- 用户确认读取歌曲与基本播放控制正常。
- 已检查歌单读取、翻页、无法读取的歌单提示；页面逐级返回通过。
- 15 项离线 Android 网络模拟回归曾在 1.0.3 通过。后续界面/图标改动未重新运行全部真机用例。
- 1.0.6 release 覆盖安装通过，授权保留，圆形 PNG 资源设置 icon/roundIcon。

## 尚未完成的验收

## 1.0.8 菜单风格统一

表冠模式选择、设备转移及退出登录使用统一黑底圆屏菜单，选中/主要操作用 Spotify 绿，保留取消及系统返回。表冠事件在菜单打开时仅滚动菜单，不传到背后的音量/进度页。

release 构建、lint 和 15 项既有单元测试通过。真机检查三个表冠选项显示完整、当前项勾选、系统返回和左上关闭均回原调节页、重新打开菜单正常；覆盖安装保留授权。未执行真实设备转移或退出登录，避免改变账号/播放状态。
